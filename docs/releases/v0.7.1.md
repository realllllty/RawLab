# RawLab v0.7.1

Version `0.7.1`, build `12`. Fork release:
[realllllty/RawLab v0.7.1](https://github.com/realllllty/RawLab/releases/tag/v0.7.1).
It is upstream [v0.7.0](v0.7.0.md) plus Nikon High Efficiency NEF decoding,
built by GitHub Actions. It is not an official
[dancancer/RawLab](https://github.com/dancancer/RawLab) release.

本版本是 fork [realllllty/RawLab](https://github.com/realllllty/RawLab) 的发布：在上游
v0.7.0 基础上增加尼康高效率（HE/HE*）NEF 解码，由 GitHub Actions 构建，不是上游官方发布。

## 新增 / What's New

- 打开和导出尼康 **High Efficiency（HE）** 与 **High Efficiency\*（HE\*）** 压缩的 NEF，
  不再提示不支持。此前 Z9、Z8、Zf、Z6III、Z5II、Z50II 等机身以这两种模式拍摄的文件
  都会被拒绝。无损压缩、未压缩等其他 NEF 的解码不变。
- Decode Nikon NEF files recorded with High Efficiency (HE) and High
  Efficiency* (HE*) compression instead of rejecting them. Other NEF
  compression modes keep their existing decoder.

解码结果与 Adobe DNG Converter 18.2 写出的原始 CFA **逐像素完全一致**（6 个样片、
2.3 亿个样本、差异为 0），随后的白平衡、色彩和导出流程与无损 NEF 完全相同。
The decoded CFA matches Adobe DNG Converter 18.2 at every sample of six test
files; white balance, colour and export then follow the lossless NEF path.

## 安装 / Installation

解压后把 `RawLab Mac.app` 拖入“应用程序”。应用为 ad-hoc 签名、未经 Apple 公证，首次打开时
macOS 可能拦截：在 Finder 中按住 Control 点按应用并选择“打开”，或在终端执行
`xattr -dr com.apple.quarantine "/Applications/RawLab Mac.app"`。

Unzip and move `RawLab Mac.app` to Applications. The app is ad-hoc signed and
not notarized; if macOS blocks it, Control-click the app and choose Open, or
run the `xattr` command above.

应用内“检查更新”指向上游仓库，上游新版本发布后会提示更新；在上游合并 HE 支持之前，
升级到上游版本会失去 HE/HE* 解码。
The built-in update check follows the upstream repository; an upstream release
without this change would not decode HE/HE* files.

## 验证与限制 / Validation and Limits

详见[验证记录](../verification-nikon-he-2026-10-16.md)。

- 与 Adobe DNG Converter 18.2 (2482) 的逐像素比较：Z8、Z9、Zf 的 HE 与 HE* 共 6 个
  raw.pixls.us（CC0）样片全部一致；无损对照同样一致。
- 两个 macOS 包都在 GitHub 托管的 macOS 15 runner 上从源码构建，通过打包检查（架构、
  最低系统、依赖闭包、签名）、核心回归，以及 9 个样片经 LibRaw、核心和应用导出的端到端测试。
- 实际解码过的机身只有 Z8、Z9 和 Zf；Z6III、Z5II、Z50II、ZR 及裁切模式预期使用相同
  码流配置但未经本仓库验证，配置不符的文件会被拒绝而不是输出坏图。
- 没有人工 GUI 操作测试，也没有在物理 macOS 15 设备上运行。
