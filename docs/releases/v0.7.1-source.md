# Rebuilding RawLab v0.7.1

Use the `v0.7.1` tag of <https://github.com/realllllty/RawLab>. Relative to
upstream `v0.7.0` (`c7f12db`), it adds the Nikon HE/HE* decoder
(`lutools/third_party/nikon-he`), its LibRaw hooks in
`lutools/cmake/patch-libraw.cmake`, tests, version 0.7.1/build 12, release
documents, the hosted build workflow and the Xcode 26 `lipo` argument order
from upstream `707c78e`. Client, rendering and colour code is unchanged.

`LibRaw-0.22.2-patched-source.tar.gz` has the same layout as earlier releases:
`LibRaw-0.22.2/` with every RawLab patch applied (including
`src/decoders/rawlab_nikon_he_decoder.h`), the pinned LibRaw-cmake wrapper and
`rawlab-build/` with the patch script and build files. The patch is idempotent:

```sh
cmake -DLIBRAW_SOURCE_DIR="$PWD/LibRaw-0.22.2" \
  -P rawlab-build/lutools/cmake/patch-libraw.cmake
```

`RawLab-0.7.1-dependency-sources.tar.gz` holds the pinned third-party archives
the macOS build downloaded, plus the Homebrew GLib, gettext and PCRE2 sources
whose libraries are bundled, each with SHA-256 in its `SHA256SUMS`.

## macOS

The packages come from `.github/workflows/macos-release.yml` on GitHub's
`macos-15` (arm64) and `macos-15-intel` (x86_64) runners. Locally, with Xcode,
CMake, pkg-config and Homebrew GLib for the target architecture:

```sh
export MACOSX_DEPLOYMENT_TARGET=15.0 RAWLAB_ARCH=arm64   # or x86_64
export DEVELOPER_DIR="$(xcode-select -p)" SDKROOT="$(xcrun --sdk macosx --show-sdk-path)"
RAWLAB_BUILD_DIR="$PWD/lutools/build-release-$RAWLAB_ARCH" \
  RAWLAB_APP_PATH="$PWD/build/release-$RAWLAB_ARCH/RawLab Mac.app" \
  bash RawLabMac/build.sh
```

`build.sh` builds the hash-pinned dependencies (including the patched LibRaw),
the core and the app, embeds runtime libraries and licenses, applies an ad-hoc
signature and runs `RawLabMac/tests/bundle.sh`. Homebrew GLib must have a
minimum OS no newer than the deployment target; on a newer host, provide a GLib
built for macOS 15. The build neither notarizes nor uses Developer ID.

## Nikon HE checks

```sh
ctest --test-dir "lutools/build-release-$RAWLAB_ARCH" --output-on-failure -R nikon_he
python3 lutools/tests/run_nikon_he_samples.py --samples DIR \
  --tool "lutools/build-release-$RAWLAB_ARCH/nikon_he_tests"
```

`DIR` holds the raw.pixls.us files named in
`lutools/tests/nikon-he-raw-samples.json` (CC0, pinned by SHA-256; never
bundled). The same manifest works with `lutools/tests/run_raw_compatibility.py`.

Windows, Android and iOS build instructions are unchanged from
[v0.7.0](v0.7.0-source.md); they apply the same LibRaw patch but were not built
for this release.
